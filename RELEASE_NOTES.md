Meet PixelRick: a small animated desktop scientist for Windows 10/11 x64.

**Download PixelRick-Setup.exe** for the normal install. No .NET, Python, or
developer tools are needed. PixelRick-Portable.zip is the extract-and-run alternative.

Includes 17 character animations, 8 effects, wandering, naps, click reactions,
dragging and throws, portal travel, tray controls, and persistent settings.

See the README for the animated demo, controls, and artwork licensing notice.
SHA256SUMS.txt contains checksums for both downloads.

Version 0.1.0 is an initial review release. The executables are unsigned.
Mixed-DPI multi-monitor arrangements need broader hardware testing.
